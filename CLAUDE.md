# Instruções para o assistente

Antes de responder qualquer coisa sobre este repositório:

1. Leia [`CONTEXTO.md`](CONTEXTO.md): regras de colaboração, decisões, status e próximo passo.
2. Leia a fase atual em [`docs/PLANEJAMENTO.md`](docs/PLANEJAMENTO.md).

Resumo das regras: o usuário escreve o código; o assistente instrui, entrega o código pelo chat, valida e explica conceitos. O assistente só edita `CONTEXTO.md`, `CLAUDE.md` e `docs/PLANEJAMENTO.md`, e mantém o `CONTEXTO.md` atualizado ao fim de cada passo.
